# Dot Knit Maker

かぎ針編みの細編みをドット絵として設計し、実際に編むときの段ごとの色指示も確認できるブラウザアプリです。PCだけでなく、スマホやタブレットでの操作を主な利用場面として設計しています。iPadでは Apple Pencil を含むペン入力を使ってグリッドに直接描画できます。

## できること

- 作品の新規作成、名前付き保存、複製保存、削除、お気に入り
- 行・列数を指定したドット絵の編集、パレット編集、ペンサイズ（1〜3）変更
- Pointer Events によるマウス・指・スタイラス入力。線を速く引いても中間のマスを補完
- キャンバスの拡大縮小・移動、取り消し／やり直し（最大50件）
- 画像の読み込み、下絵の透過・位置・大きVさ調整、現在のパレットへの簡易変換
- ゲージからの仕上がりサイズ・色別の毛糸使用量の概算
- 段ごとの色数指示、進捗チェック、編み方向の切り替え、図案の90度回転
- IndexedDB を利用した編集中データと作品一覧のブラウザ内保存

## 使い方

```bash
npm install
npm run dev
```

表示されたローカルURLを、同一ネットワーク上のスマホ／タブレットから開く場合は、Vite のホスト公開オプションを付けて起動してください。

```bash
npm run dev -- --host
```

### タブレットで描く

1. 「さくひん」から新しい作品を作成します。
2. 右側のパレットで色、丸いボタンでペンサイズを選びます。
3. キャンバスを Apple Pencil、指、またはマウスでなぞって描きます。
4. 拡大したい場合は `＋`／`−`、表示位置を動かす場合は手のひらツールを使います。

キャンバス操作中はブラウザのスクロールや拡大ジェスチャーを抑止します。一方、キャンバス外は通常どおりページをスクロールできます。

## データについて

保存先はこのブラウザの IndexedDB です。別の端末・別のブラウザ・ブラウザデータの削除後には引き継がれません。大切な図案のエクスポート／インポート機能は、現時点では未実装です。

## 技術構成

- React 19 + TypeScript
- Vite
- idb-keyval（IndexedDB）
- Canvas API（画像の色をパレットへ近似）
- GitHub Pages（`/dot_knit_maker/` 配下で公開）

## 現在の制約と次の改善候補

- 画像変換はディザリングや高度な減色ではなく、各マスを登録パレットの最も近い色に置き換える簡易方式です。
- 下絵の位置・拡大率、ゲージ、編み進捗は作品データに含めていません。
- ブラウザ内保存のみのため、図案のPNG／JSON書き出し・読み込みが必要です。
- 色の削除、塗りつぶし、消しゴム専用ツールは未実装です（背景色を選んで上書きすることはできます）。
- タブレットの実機テストは、対象のiPadOS／Android端末で最終確認が必要です。
